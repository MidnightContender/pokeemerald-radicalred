## Other fixes

- **Rockruff and Cosmoem**: the fork listed `EVO_ITEM` as a condition, which the game read as "not at time *n*". That is always true, so Rockruff always became Midday Lycanroc and Cosmoem always became Solgaleo. These now check the held stone (`IF_HOLD_ITEM`), so a Sun, Dusk or Moon Stone picks the form at the evolution level. RR's time-of-day routes are added after them.

## Already matching or left alone

- **Trade evolutions**: RR uses a Link Cable item. The fork already has the Linking Cord for plain trade evolutions. For the held-item trades (Rhydon, Electabuzz, Magmar, Porygon, Dusclops, Karrablast, Shelmet), the Linking Cord is now added too.
- Tyrogue, Wurmple, Pancham, Toxel, Eevee, Nincada/Shedinja and Tandemaus already evolve the RR way in the fork.
- Burmy's cloak forms: RR only lists the Plant form, so all three cloaks follow its level.
